Frequently asked questions

Can a hotel in Thika use Ndovesha?

Ndovesha is an online platform, so you can sign up and try it from Thika. New accounts start with 200 free credits.

What does it cost for a hotel in Thika?

You can start with 200 free credits. Each AI Worker uses credits based on what you ask it to do, and credits included in a plan reset every month. The Starter plan includes 1,000 credits a month. See the pricing page for details.

Can restaurant charges go on the room bill?

You can ask for restaurant and bar orders that can be charged to a guest's room.

What problems can a system fix for hotels?

Room bookings sit in a diary and double bookings still happen; Guests booking by phone or WhatsApp are hard to track. Describe the ones you have and ask for a system that handles them.

What could hotels build first?

You could begin with room calendar and manager dashboard, then add more as the team gets comfortable.

Do different tasks use different amounts of credits?

Yes. Each AI Worker uses credits based on the capability you deploy. A Copy Worker writing a caption uses fewer credits than a Web App Worker deploying a full application. The pricing page lists the costs.
